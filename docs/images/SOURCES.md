## XMonad Bind, XMonad Tall and Arch Linux Console

These three are theme folders the author made for their own machine with the
theme skill. They are not in this repository or the package, because they
draw other projects' logos; the README and the homepage show them as
screenshots of what a theme folder can do. Each was taken with
`gpui-greeter preview --shot` from a copy of the folder, as the skill takes
them. In the copies, XMonad Tall's slideshow holds the five photographs
above, scaled to 1920 pixels wide, and Arch Linux Console's facts come from a
made-up machine: its kernel, uptime, packages, CPU and graphics card are not
anyone's.
